Q1: Java Features 5 headings
  • Platform Independent: Bytecode runs on any JVM.
  • Object Oriented: Everything is an object.
  • Multithreaded: Built-in thread support.
  • Secure: No pointers, bytecode verifier, Security manager.
  • Robust: Exception handling & strong memory.
// Robust demo
try {
    int x = 10 / 0;
} catch(ArithmeticException e) {
    System.out.println("Caught: " + e.getMessage());
} finally {
    System.out.println("Continues!");
}
Q2: OOP & Interface SI & Diamond
  • Diamond Problem: B & C have same method, D extends both = Ambiguity.
  • Interface Solution: implements both, override, call B.super.show().
  • SI Formula: (p * r * t) / 100
// Multiple Inheritance Interface
interface B { default void show() { System.out.println("B"); } }
interface C { default void show() { System.out.println("C"); } }
class D implements B, C {
    public void show() {
        B.super.show(); // select B
    }
}
